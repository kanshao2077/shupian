# 薯片小红书发布助手

这个扩展只做一件事：把“薯片”网页里准备好的标题、正文和卡片图填入小红书创作后台。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择解压后的 `browser-extension` 文件夹。
4. 打开 `https://www.kanshao2077.cn/shupian/`，确认作者区下方显示“发布助手已连接”。
5. 补齐标题、正文和图片，点击“一键填充小红书”。
6. 扩展会打开小红书创作后台并填入素材；校对后由你点击最终发布。

本地开发时也可以打开 `http://localhost:4173/`。

## 安全边界

- 扩展不会点击“发布”。
- 发布素材只保存在浏览器本地扩展存储中。
- 如果小红书调整发布页结构，扩展会显示未完整填入的提示，不会继续误操作。
- 当前扩展同时支持 GitHub Pages 在线版和本地 `4173` 端口。
